# Library API index

Look up a namespace below, then follow its type to the signature list. Each list links to its declaration for attributes and implementation details. For inherited members, also consult the base type's entry. Identical signatures from platform branches appear once. Generic arguments, parameter names and default values follow the Bolt source. A member of a static class is called through the type name even when its declaration omits the word `static`.

The global namespace contains declarations available by their unqualified names. In particular, use `NumberConverter` directly.

## Compiler-provided facilities

The [built-in operations reference](api/Intrinsics.md) lists numeric and string members, arrays, math functions, type queries, arenas and runtime execution methods.

Primitive types, arrays, `Arena`, `Math`, `Type` and `Runtime` also have compiler-provided operations. The [language reference](Language.md), [arena example](../examples/ArenasProject/Main.bolt), [generic math constants](../examples/GenericConstants.bolt), [type queries](../examples/FeatureProject/Operations.bolt) and [runtime example](../examples/Runtime.bolt) demonstrate these entry points. IDE completion shows the eligible members for the actual receiver and specialization.
